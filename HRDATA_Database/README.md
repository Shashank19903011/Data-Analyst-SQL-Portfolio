# HRDATA Database

## Overview

The **HRDATA Database** contains the HR Employee Attrition dataset used for SQL practice, data analysis, and reporting.

This project demonstrates how SQL can be used to explore employee data, analyze workforce trends, and answer business questions related to employee attrition.

---

## Dataset Information

**Dataset Name**

HR Analytics Employee Attrition & Performance

**File**

`WA_Fn-UseC_-HR-Employee-Attrition.csv`

**Records**

- 1,470 Employees

**Columns**

- 35 Attributes

## Business Questions

This project answers questions such as:

- What is the overall employee attrition rate?
- Which department has the highest attrition?
- Which job roles have the highest average salary?
- Which employees work overtime?
- How does work-life balance impact attrition?
- Which departments have the highest employee count?
